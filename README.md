# 货小玲 · 微信小程序

这是一个原生微信小程序 MVP，产品心智是“老板的生意备忘秘书”：

> 谁欠钱、哪单要交、哪个报价要跟，打开就知道；说一句、打一段、粘贴聊天，它帮你记。

## 已实现

- 首页今日工作台：待收款、临近交期、报价待跟进、待整理数量摘要
- 三种录入入口：语音录音、手动输入、粘贴聊天记录
- AI 解析确认卡片：本地规则解析器先生成草稿，用户确认后保存
- 待整理记录：识别不完整或不确定时先保存，不丢信息
- 报价：新建、历史列表、3 天待跟进、复制跟进话术、转订单
- 订单：列表、进度更新、交期提醒、生成应收款
- 收款：应收款、部分收款、结清、催款话术复制、催款记录
- 客户档案：手机号可选，支持临时客户，保存业务记录时自动生成
- 问一句：查询欠款、近期交期、待跟进报价、客户上次报价

## 当前实现边界

- 数据使用 `wx.setStorageSync` 本地存储，便于快速验证闭环。
- `utils/parser.js` 是可替换的本地规则解析器，不是真实大模型。
- 语音入口已接入小程序录音能力；语音转文字需要后端或第三方服务，接口契约见 `docs/api-contract.md`。
- 催款首版只做“生成话术 + 复制 + 手动记录”，不自动跳微信私聊，不自动发送。
- 首页默认只显示数量摘要，不直接暴露客户名和金额。

## 本地打开

1. 打开微信开发者工具。
2. 导入当前仓库根目录。
3. AppID 可先使用测试号或保留 `touristappid` 体验页面。
4. 编译后从“开始使用”进入，选择或跳过行业，再开始记第一笔。

## AI 接口联调

前端默认请求 `https://api.baizeji.com`：

- 记一笔：`POST /api/ai/parse`
- 问一句：`POST /api/ai/query`

跑一次线上接口合同冒烟测试：

```bash
node scripts/ai-contract-smoke.js
```

如需测试其他环境：

```bash
API_BASE_URL=https://api.example.com node scripts/ai-contract-smoke.js
```
