# 小玲角色资产与一致性规范

本文件用于保证货小玲在首屏、首页、空状态、帮助页和营销素材中的人物身份尽量一致。涉及小玲的新表情、新动作或新场景时，必须先读取本文件，并使用同一母版图作为参考，不得只凭文字重新想象角色。

## 1. 一致性的实现原则

生成模型无法仅靠一句提示词保证每次 100% 画出同一个人。项目采用以下办法提高稳定性：

1. 同一张母版图始终作为角色身份锚点。
2. 发型、脸型、眼睛、服装、领巾和画风作为不可随意更改的固定特征。
3. 新姿态先生成候选图，按本文件逐项审核，通过后才加入正式角色库。
4. 已有合适姿态时直接复用正式素材，不重复生成。
5. 文件只新增版本，不覆盖已确认的角色素材。

如果未来需要大量连续动作并要求绝对稳定，应升级为经过人工统一修稿的二维角色立绘库，或制作可绑定骨骼的二维/三维角色模型。当前阶段最适合小程序的是“母版 + 有限数量已确认姿态”的角色资产库。

## 2. 角色母版与正式素材

| 用途 | 文件 | 状态 |
| --- | --- | --- |
| 角色身份与画风母版 | `assets/onboarding/xiaoling-dialogue.webp` | 最高参考，不覆盖 |
| 首页倾听姿态 | `assets/characters/xiaoling/xiaoling-home-listening-v1.jpg` | 首页语音入口正式素材 |

母版图中右侧女性是小玲。左侧老板、背景和确认卡不是角色身份的一部分。

## 3. 不可改变的角色特征

- 年轻、亲切、干练的中国女性生意助理气质，不幼态化，不做夸张二次元比例。
- 温暖的棕色大眼睛，柔和鹅蛋脸，五官比例以母版为准。
- 深棕接近黑色的高盘发，额前和耳边保留自然碎发。
- 小巧珍珠或暖金色耳饰。
- 米白色衬衫，珊瑚橙领巾；除非具体场景经过产品负责人确认，不改制服识别色。
- 柔和、精致、半写实的商业插画风格；光线温暖，线条细腻，不转成 3D、扁平卡通或写实照片。
- 性格关键词：可靠、会倾听、利落、有耐心，不卖萌过度。

## 4. 新姿态生成流程

1. 明确素材使用位置、实际显示尺寸和要表达的行为。
2. 加载母版图 `assets/onboarding/xiaoling-dialogue.webp` 作为身份参考图。
3. 只改变任务要求的表情、动作、视线和构图，其余固定特征全部锁定。
4. 先检查原尺寸，再缩小到页面真实尺寸检查脸是否仍可辨认。
5. 检查手指、手臂、耳饰、发丝、衣领和领巾是否正常。
6. 通过产品负责人确认后，以新版本文件名加入 `assets/characters/xiaoling/`。
7. 页面只引用已确认素材，不直接引用临时生成文件。

## 5. 标准生成提示词模板

```text
Use case: identity-preserve
Asset type: 货小玲微信小程序中的小玲角色素材，说明具体页面和显示尺寸
Input images: Image 1 是小玲唯一身份与画风母版，只参考右侧女性
Primary request: 保持同一个小玲，只改变为“说明新表情、动作和视线”
Subject: 锁定母版的脸型、棕色眼睛、高盘发与自然碎发、耳饰、米白衬衫、珊瑚橙领巾、年龄和气质
Style/medium: 与母版相同的柔和精致半写实商业插画
Composition/framing: 说明全身/半身/头像、朝向、裁切和留白
Lighting/mood: 明亮、温暖、可靠、亲切
Constraints: 只改变本次动作和表情；不得重新设计脸、发型、服装和画风；只出现一个小玲；无文字、无水印
Avoid: 幼态 Q 版、夸张动漫眼睛、3D、照片写实、额外人物、多余手指、错误肢体、随机饰品
```

## 6. 审核清单

- 缩小到页面实际尺寸后，第一眼仍像母版中的小玲。
- 脸型、眼睛、鼻口比例和表观年龄没有明显漂移。
- 高盘发、碎发、耳饰、米白衬衫和珊瑚橙领巾完整。
- 表情符合“可靠的 AI 生意助理”，不过度卖萌或夸张。
- 动作能在小尺寸中被看懂，手指和肢体结构正常。
- 构图没有遮挡页面主文案或操作按钮。
- 背景、边缘和压缩质量适合小程序，不含文字、水印和无关人物。

## 7. 文件命名

使用 `xiaoling-页面或场景-动作-v版本.扩展名`，例如：

```text
xiaoling-home-listening-v1.jpg
xiaoling-empty-orders-checking-v1.webp
xiaoling-help-pointing-v2.webp
```

生成新版本时保留旧版本，页面确认切换完成后再决定是否清理未使用素材。
