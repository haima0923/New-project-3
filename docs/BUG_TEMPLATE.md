## 优先级

请选择一个：

- 高：影响核心使用，老板无法记录或查看关键事项。
- 中：影响部分场景，但还有办法绕过。
- 低：显示、文案或体验问题，不影响主要流程。

## 验收标准

这个问题修好后，应该满足什么条件？

例如：

- 相同输入可以正常保存。
- 对应页面能看到真实记录。
- 刷新或重新打开小程序后记录还在。
- 不出现假数据。
- 不影响其他记一笔类型。
